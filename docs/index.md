# Welcome to sample_docs

**sample_docs** is a general-purpose MkDocs starter template for internal or public team documentation.

It is designed to help teams publish clear, structured docs without spending much time on setup.

---

## What this template includes

- A clean home page
- A simple getting-started section
- A reusable integrations section
- Export guides
- A FAQ page
- GitHub Pages deployment with GitHub Actions

---

## Suggested use cases

You can adapt this template for:

- Product documentation
- Internal team handbooks
- Operations runbooks
- Integration guides
- Customer help centers

---

## Documentation principles

This starter follows a few simple rules:

1. Keep each page focused on one topic.
2. Use short sections with clear headings.
3. Link related pages together.
4. Reuse the same structure across similar docs.
