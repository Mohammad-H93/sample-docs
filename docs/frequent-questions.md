# Frequently Asked Questions

## General

??? question "How do I use this template?"
    Start by editing the project name, homepage, navigation, and sample pages.

??? question "Can I remove sections I do not need?"
    Yes. Delete the markdown files you do not want and update `mkdocs.yml` to match.

## Writing

??? question "What structure should a page follow?"
    A good default is: purpose, prerequisites, steps, troubleshooting, and related pages.

??? question "How do I keep docs consistent across the team?"
    Reuse the same headings and page patterns for similar content.

## Deployment

??? question "Can this be deployed automatically?"
    Yes. The included GitHub Actions workflow can publish the site to GitHub Pages.
