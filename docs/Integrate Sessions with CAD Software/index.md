# Integrations Overview

This section shows a reusable pattern for documenting integrations with external tools, platforms, or services.

## What to document for each integration

For consistency, each integration can have three pages:

- **Overview**: what the integration does
- **Sync**: how data or configuration is exchanged
- **Generate**: what output or workflow is produced

## Why this structure helps

It keeps similar tools documented in the same way, which makes it easier for contributors to add content and for readers to find what they need.
