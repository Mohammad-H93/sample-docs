# Getting Started

## Purpose

This page explains how to use the template as a starting point for your own documentation site.

---

## Recommended first steps

1. Rename the project in `mkdocs.yml`.
2. Replace the homepage content in `docs/index.md`.
3. Update the navigation to match your real sections.
4. Remove sample pages you do not need.
5. Add your own guides, references, and FAQ entries.

---

## Suggested folder ownership

A simple setup that works well for most teams:

- `docs/` for all markdown content
- `docs/assets/` for logos and icons
- `docs/stylesheets/` for custom styling
- `.github/workflows/` for deployment automation

---

## Writing pattern

Use this structure for most pages:

- Purpose
- When to use
- Steps
- Examples
- Troubleshooting
- Related pages
